# Intent layer

This directory defines the confirmed V1 outcome and product boundary. It answers
"why" and "what must ultimately be true", not "how to implement it".

- [`PROJECT_GOALS.md`](PROJECT_GOALS.md) is the binding V1 goal and acceptance
  baseline.

Unresolved product choices remain explicit unknowns. They must not be converted
into implementation defaults by a planner, developer or reviewer.
