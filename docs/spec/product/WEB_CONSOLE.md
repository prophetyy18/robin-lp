# V1 Web 控制台规格

状态：已确认范围，细节可继续版本化
最后更新：2026-09-19

## 1. 文档职责

本文档是 V1 Web 控制台的规范层文档，定义必须提供的页面、信息、操作边界和
验收行为。产品使命与最终范围以 `PROJECT_GOALS.md` 为准；任务顺序和交付证据
由 `todo/README.md` 管理；组件、框架和部署方式属于 Architecture/ADR。

V1 首先服务一个系统所有者，不实现公众注册、多租户、策略市场或社交功能。

## 2. 全局交互与安全规则

### `WEB-GLOBAL-001` — 状态必须可辨认

每个页面始终显示当前 Robinhood Chain 环境、运行模式（backtest、testnet、
paper、live）、目标 token、活动 PoolKey、活动策略版本、数据新鲜度和暂停状态。
paper、testnet 与 mainnet live 不得只依靠颜色区分，也不得共享容易误认的操作
入口或结果标签。

每个页面还必须显示当前活动数据集版本和该数据集的报告计价单位：USDG、合格 USD
稳定币，或明确标注为波动计价的 ETH 展示。以美元计价的数据集与 `RELATIVE_ONLY`
数据集必须在文本和视觉上都可辨认，`RELATIVE_ONLY` 结果不得出现美元符号或任何
USD 计价字段；数据集版本、报告计价单位及其估值资格随页面可展开查看
（`WEB-GLOBAL-002`）。

### `WEB-GLOBAL-002` — 证据优先

价格、收益、风险、资格和交易状态必须能够展开查看来源、观测/可用时间、区块、
版本和原因代码。未知、部分、冲突和不可用必须明确展示，不能显示为零、正常或
通过。Address、PoolKey、PoolId、交易哈希和 approval ID 应完整可复制。

### `WEB-GLOBAL-003` — 写操作分级

普通筛选、比较和草稿编辑不改变运行状态。选择 token/Pool/策略、提高权限或
敞口、晋级 live、解除锁定式暂停等风险增加操作必须经过影响预览、身份确认、
明确确认，并生成不可变版本和审计事件。降低权限、暂停、减仓、退出和撤销授权
不能被增加风险的流程阻塞。

### `WEB-GLOBAL-004` — 秘密不进入 Web

Web 不接受、显示或返回私钥、Keystore 密码、助记词、RPC 凭据或企业微信
Webhook。敏感配置只显示是否已配置、版本或不可逆摘要。浏览器关闭或 Web 服务
重启不得停止后台采集、策略、风险、执行或核对。

### `WEB-GLOBAL-005` — 紧急入口持续可见

所有运行页面必须提供清晰的暂停入口和当前暂停级别。风险降低操作在数据不足、
超限或暂停时仍须可达；界面不得把“退出 LP”和“将资产转到外部地址”合并成
一个隐含操作。

## 3. 必需页面

### `WEB-PAGE-001` — 总览

至少展示当前环境/模式、目标 token、活动池和策略、signer 锁定状态、钱包总值
与可用额度、LP 仓位、累计/当期 PnL、费用、Gas、主要风险、数据健康、待处理
审批和告警。关键卡片可跳转到其证据或操作页面。

### `WEB-PAGE-002` — Token 准入

支持以 contract address 输入和切换目标 token；分别展示目标和配对 token 的
技术资格、项目风险、holder/供应、外部资料及覆盖状态；管理 `HOLD`、`LP`、
`AUTO_SWAP`、USDG 敞口、提醒、审批、复核、拒绝和撤销。硬性技术门槛必须与
可由用户接受的项目风险分区展示，界面不能提供覆盖硬门槛的控件。

### `WEB-PAGE-003` — Pool 发现与选择

展示包含目标 token 的全部候选 PoolKey，包括未批准、不支持和被拒绝的池。
每行至少包含完整 PoolKey/PoolId、配对 token、fee/实际 fee、tick spacing、
Hook 身份和 flags、相关 contract/code hash、初始化区块、流动性、交易量、数据
覆盖、支持等级及原因。活动池使用单选语义；选择、切换和撤销必须记录版本。

### `WEB-PAGE-004` — 策略研究与回测

管理和比较策略逻辑/参数/代码版本及实验 manifest。至少可视化价格与 Range、
流动性分布、交易量、净值、回撤、token 库存、费用、Gas、滑点、IL/LVR、资金
效率和样本外表现；比较等待、立即重建、条件重建和退出等反事实路径。失败、
亏损和被淘汰候选不得隐藏；推荐不产生执行权限。

绩效必须按市场状态与时间切片分解展示，而不是只给一个总体数字；每个切片同时
报告其背后的独立 episode 数量，并在样本允许时给出不确定性区间。样本不足以支持
区间时必须显示 `UNCERTAIN`，不得用点估计替代。所用切分口径、episode 计数、
区间及其置信水平必须随页面可展开查看（`WEB-GLOBAL-002`）。

### `WEB-PAGE-005` — Paper 与 Live 运行

以清楚隔离的模式展示实时信号、当前价格/Range、LP liquidity、两种 token 原始
数量与 USDG 等值、未领取费用、待执行/已拒绝意图、paper fills 或真实交易、
链上确认和账本核对。每个动作显示策略原因、授权版本、风险结果和执行状态；
不得把模拟回执显示为链上回执。

### `WEB-PAGE-006` — 授权与风险

管理活动策略授权、全局钱包上限、策略 LP 上限、两种 token 敞口、单笔/每日
周转、滑点、Gas、损失、回撤和允许操作。展示 backtest → testnet → post-testnet
paper/shadow → 安全复核 → live 的正式证据门槛、当前级别和阻断原因。testnet 前的
preliminary paper 必须标为仅实现验证，不得显示为 live 晋级证据。任何提高权限或上限的修改先
形成草稿并展示受影响仓位、Pool、策略和旧授权失效结果。

### `WEB-PAGE-007` — 审计与运维

展示不可变审计时间线、RPC/数据同步、覆盖缺口、重组、交易/nonce、账本核对、
暂停原因、企业微信通知状态、备份和恢复证据。提供人工暂停、锁定式暂停复核、
恢复、减仓和退出入口；操作前展示会执行与明确不会执行的动作。

### `WEB-PAGE-008` — 数据覆盖与下载

以实测的逐池数据集为基准的覆盖视图：可用与缺失的区块/时间区间，以及这些区间上的
交易量、已实现波动率、swap 活动和流动性，使时段可以依据覆盖证据而不是日期猜测
选择。缺失必须显示为缺失，不得插值、补零或画成连续曲线；没有数据、尚未采集和
采集失败必须可区分。展示数据集清单及其版本、成员池、各自区块区间、报告计价单位与
估值资格、覆盖报告，并提供下载入口；下载内容不得包含任何凭据。

该页面由 T103 拥有，明确不属于 T084 的验收范围。

### `WEB-PAGE-009` — 回放与仓位检查器

指定区块上的重建池状态、当前价格附近的 tick 流动性分布、推动价格变化的 swap，以及
一个假设仓位在所选窗口内的区间、库存（token0/token1 原始整数与 `liquidity`）、
已计费用和 PnL。所有时间序列标明数据时间与可用时间；未重建、超出覆盖范围或不受
支持的状态显示为不可用，不得用当时或最新的链上状态顶替历史状态。

该页面由 T103 拥有，明确不属于 T084 的验收范围。

### `WEB-PAGE-010` — 数据集构建器

以池和区块区间为单位构建数据集：为 train、validation、test 和 backtest 指定分段
角色，把池留出和时间留出作为显式选择而不是附带结果，并显示所选池的覆盖与计价
资格摘要。保存产生带版本、可复现且不可编辑的数据集定义，重新打开同一版本必须得到
相同的成员池、区块区间与分段角色；低于 `backtest` support level 的池不得从界面
加入。

该页面由 T103 拥有，明确不属于 T084 的验收范围。

### `WEB-PAGE-011` — 模型实验室

针对选定数据集版本的训练与评估运行：特征重要性、概率校准、分位数覆盖率、样本量与
独立 episode 数披露、规则基线对照，以及未通过经济评估的模型的 rejection 记录。
预测诊断必须与事件驱动回测给出的 LP 经济结论并排展示，使一个良好的预测指标不能被
读成良好的策略；失败的、退化的和不可识别的模型与成功模型一并保留且可复现。

该页面由 T103 拥有，明确不属于 T084 的验收范围。

## 4. 可视化最低要求

- 所有时间序列明确时区、数据时间与可用时间，支持查看原始点和缺口。
- 价格图叠加 tick Range、入场/出区间/再平衡/退出事件，不以收益曲线替代价格。
- PnL 图可拆分本金价格变化、LP fee、Gas、滑点、Hook delta、Swap/再平衡成本
  和未解释残差。
- 仓位图同时显示 liquidity、token0/token1 原始数量和 USDG 等值；不得把
  `liquidityDelta` 直接标成 USDG。
- 对比视图采用相同数据范围、估值来源和成本口径；不同口径必须阻止直接排名。
- 覆盖图以实测数据画出可用与缺失区间，缺失不得插值、补零或与“已覆盖”混同显示。
- 回放时间线对齐区块、数据时间与可用时间，显示价格、tick Range、事件，以及每个
  时间点上当时可见与不可见的数据边界。
- 数据集与标签溯源可展开查看：数据集版本、成员池与各自区块区间、报告计价单位与
  估值资格、特征与标签的窗口、horizon 及其可观测时刻。
- 模型诊断与经济结论并排展示：特征重要性、概率校准、分位数覆盖率、样本量与独立
  episode 数；不得以预测指标替代策略绩效。

## 5. V1 明确不做

- 公众注册、多租户、角色市场和策略商店；
- 自动选择目标 token、活动池或 live 策略；
- 在 Web 中生成、导入或解锁私钥；
- 通过一个开关绕过晋级、审批、风险或核对；
- 为移动端提供完整交易操作体验；V1 只要求桌面浏览器可用，并保证关键状态在
  窄屏下不会被隐藏或误读。

## 6. 页面级验收

每个页面至少通过正常、空数据、部分数据、冲突、过期、权限不足、后台不可用和
安全暂停状态测试。风险写操作必须通过取消、重复提交、会话过期、并发版本变化、
后台超时和审计落盘失败测试；任一不确定结果不得显示为成功。关键图表和表格应
完成键盘操作、文本替代、非颜色状态表达和常见桌面分辨率检查。
