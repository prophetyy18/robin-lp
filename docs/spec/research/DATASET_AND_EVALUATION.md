# V1 研究数据集与模型评估规格

状态：已确认基线

## 1. 文档职责

本文档定义 V1 研究路径的输入单元、切分协议、训练与评估纪律，以及模型进入策略层
的边界。它不定义指标含义（见
[`../strategy/LP_METRICS.md`](../strategy/LP_METRICS.md)），不定义经济口径（见
[`../strategy/STRATEGY_ECONOMICS.md`](../strategy/STRATEGY_ECONOMICS.md)），也不
定义任务顺序（由 `todo/README.md` 管理）。

适用范围：`ADR-014` 定义的**研究范围**。执行范围的一切约束不受本文档影响。

## 2. 数据集是研究的输入单元

### `DS-001` — 数据集身份

研究不消费"某个时间范围"，只消费**数据集**。一个数据集绑定：

- 数据集 ID 与版本号；
- 成员 `(chain_id, PoolKey)` 列表，及每个成员自己的区块区间；
- 每个成员的 support level 与覆盖报告；
- 计价单位及其估值资格（`QUALIFIED` / `RELATIVE_ONLY`）；
- 该数据集解析到底层哪些分区，以及这些分区携带的 schema 与 decode 版本；
- 内容哈希。

### `DS-002` — 不可变与版本化

发布是追加。**已发布的数据集版本永不被编辑**：扩大范围、增加成员或修正覆盖都产生
新版本。两个覆盖同一分区的数据集彼此隔离，在一个数据集上算出的结果不得归属到
另一个。

### `DS-003` — 计价资格

按 `ADR-014` 第 3 条应用计价层级。声明为 `RELATIVE_ONLY` 的数据集**不得包含任何
以美元计价的字段**，包括 PnL、价值、费用和风险量。

### `DS-004` — 最低支持等级

成员池未达到 `backtest` support level 的数据集不得被回放、回测或用于训练。低于该
等级必须给出具名原因，而不是静默排除。

## 3. 特征与标签

### `DS-010` — 时点正确性

特征只能使用其决策时刻已经**可用**的观测。每个特征记录单位、窗口、可用时间和版本。
等价的约束是**前缀不变性**：把标签窗口之后的数据全部截断，时刻 `t` 的特征值不得
改变。

### `DS-011` — 标签与其可观测时刻

标签是前视的，必须记录其 horizon 以及它**何时变得可观测**。标签集合至少覆盖：

- 未来已实现波动率；
- 未来成交量；
- 未来费率密度；
- 未来再平衡损失代理（`M-LVR-001`）；
- 价格在 horizon 内离开候选区间的概率；
- 候选区间上的未来净 LP 收益。

模型估计的是这些**决策输入**，不是收益本身（`ADR-014` 第 5 条）。

### `DS-012` — 统计边界

模型层必须自己命名并记录一个浮点边界。边界之外，特征与标签在边缘处保持类型化、
带单位、整数精确；边界内产生的浮点值不得流入 protocol、账本或估值路径
（`ADR-004`、`ADR-014`）。

## 4. 切分与交叉验证

### `DS-020` — 禁止随机切分

随机、打乱或任何非时间的切分**禁用**。它在本问题上制造时间泄漏，并使结果失去意义。

### `DS-021` — 切分轴

至少支持三条轴，并明确区分：

- **池留出（pool holdout）**：训练与评估使用不相交的池集合；
- **时间留出（time holdout）**：评估期晚于训练期；
- **前向滚动（walk-forward）**：反复用过去训练、紧跟其后的一段评估。

在本项目的样本规模下，**池留出是主要的泛化检验**，因为链的历史长度有限，时间留出
的两侧共享几乎相同的市场状态。

### `DS-022` — purge 与 embargo

标签窗口重叠时，训练折与评估折之间必须留出等于标签 horizon 的隔离带。隔离带长度
必须随切分一同记录，并且**可以从标签定义推导**，不得手工挑选。

## 5. 训练与评估

### `DS-030` — 模型范围

模型族刻意保持小：一个可解释的线性基线（正则化与分位数回归）和一个梯度提升对照。
深度学习不在 V1 范围内。选择依据是**样本量**，而样本量由 `ADR-015` 的逐池延长历史
窗口决定：每个成员池取其自身 `Initialize` 区块到本次运行一致认定的 finalized 区块，
窗口宽度取决于该池自己的历史，而不是一个固定宽度。在该窗口下，实测区块间隔为
0.1008 秒，已固定的参考池自初始化到最近一次探测约 12 天，即约 3.4 千根 5 分钟 bar
或 288 根小时 bar；即使取满主网现有历史（约 76 天），也只约 2.2 万根 5 分钟 bar。
跨池面板由少数共享的市场状态主导，因此可用的独立观测更少：实测样本量是硬约束，
模型族刻意保持小。

### `DS-031` — 调参与选择

超参数只能在训练折上选择。评估折只能看一次，并且在候选锁定后才看。评估期上的任何
统计量——包括归一化、缺失值填补和特征筛选——都不得回流入训练。

### `DS-032` — 样本量与不确定性

每个报告必须声明观测数、计入标签重叠后的**有效样本量**和逐池分布。样本不足以支持
结论时输出 `UNCERTAIN`，不得用点估计代替。

### `DS-033` — 诊断

至少包括特征重要性、概率校准和分位数覆盖率。概率校准是核心：`P(价格离开区间)` 的
价值完全取决于它是否被校准，而不是取决于它的排序能力。

### `DS-034` — 诚实失败

模型在未见池上不优于平凡基线时必须如实报告。失败的、退化的和不可识别的模型与成功
模型一样保留且可复现。

### `DS-035` — 压力与失败场景的声明式归宿

任何稳健性、压力或抗过拟合运行都必须先写出一份场景目录，每条目录项在运行开始前就
声明该场景的唯一归宿：要么以具名 reason code 让本次运行 halt，要么把结果降级到该
条目自己具名的确定性 fallback。两种归宿只记录在这份目录里，不得事后推断或临时
决定；降级绝不等于未定义行为，也不得成为强制交易的理由（`DS-041`）。

## 6. 模型进入策略层的边界

### `DS-040` — 接口而非决策

模型实现策略层已经定义的可替换接口，消费版本化的时点输入，返回版本化、带单位的
评估。模型**不**输出仓位、规模或 tick 区间，不绕过集中风险检查，不产生 paper 或
live 权限，不得成为活动默认实现。

### `DS-041` — 降级

模型产物缺失、过期、无版本或超出训练分布时，必须**确定性地**回退到规则基线，而不是
回退到未定义行为或强制交易。

### `DS-042` — 最终判据

模型的最终判据是事件驱动回测引擎产生的 LP 经济结果。**预测指标改善而 LP 经济恶化
必须记为 rejection。** 报告必须并排展示规则基线与模型，在相同数据、资金、成本与
切分下比较，并给出：

- 独立 episode 数量；
- episode 级 bootstrap 区间；
- 按市场状态的分解，使有利的总体数字无法掩盖集中于单一状态内的亏损。

### `DS-043` — 版本与复现

每个模型产物携带内容哈希与完整溯源：数据集版本、特征配置、切分定义、超参数、随机
种子和代码版本。相同配置重跑必须产生逐字节等价的产物（排除已声明的观测性字段）。

## 7. 控制台义务

研究控制台必须让上述每一条可见，而不是只在文档里成立：覆盖与缺口按实测数据显示，
数据集定义可保存与复现，训练运行与诊断可见，经济结论与预测诊断**同时**展示，切片
结果暴露其背后的 episode 数量，`RELATIVE_ONLY` 数据集在界面上可辨认。
