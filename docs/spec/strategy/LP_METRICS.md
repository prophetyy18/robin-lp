# V1 LP 指标字典

状态：已确认基线
最后更新：2026-09-19

## 1. 文档职责

本文档定义 V1 研究报告中每一个 LP 指标的精确含义、量纲、可用时间和禁止用法。
它不定义策略阈值（那些延期到 paper trading 后评审），也不定义任务顺序。
`STRATEGY_ECONOMICS.md` 定义经济判断口径，本文档定义这些口径落到报告上的具体量。

LP 回测最常见的失败不是算错数，而是**用一个看似合理的量回答一个它回答不了的
问题**——把分摊估算的费用当作真实费用、把可领费用当作已实现收益、把年化数字
建立在不完整的区间上、或者把一个代理量当作真值报告。本文档的存在就是为了让
这些错误在评审时可见。

## 2. 通用规则

- **可用时间。** 每个指标必须记录其观测时间和**可用时间**；决策路径只能使用
  可用时间不晚于决策时刻的指标。
- **数据集版本。** 任何报告必须声明其所依赖的数据集版本；没有版本的指标不构成
  结果。
- **代理标签。** 无法直接测量的量必须显式标注为代理，并说明其参照基准。
- **年化。** 任何年化量必须同时给出原始区间长度和覆盖率；区间不完整时不得只报
  年化值。
- **量纲。** 每个指标声明其量纲（原币整数、计价单位、比例、无量纲比值）。浮动
  只允许存在于模型层自己命名的统计边界内（ADR-014 第 5 条）。
- **聚合。** 聚合必须说明其统计单位。LP 的统计单位是 **episode**（一次完整持仓
  生命周期），不是日历天；日历聚合会掩盖收益的时间集中性，只能作为辅助视图。

## 3. 费用与做市收入

### `M-FEE-001` — 历史费用（精确）

对给定区间 `[tickLower, tickUpper]`、流动性 `L` 和窗口，费用按
`feeGrowthInside` 增量积分：

```text
fees(L) = L × Σ ΔfeeGrowthInside / 2^128
```

该量对 `L` 线性，因此一次事件遍历即可得到**任意** `L` 的精确历史费用；对 tick
做前缀和后，任意候选区间都是 O(1) 查询。动态费率和 hook 抽成被自动吸收，因为它们
已经体现在 `feeGrowthInside` 的增量里。

禁止用"自身份额 × 区间内总成交量 × 费率"估算历史费用：那是预测模型，不是回放结果。

### `M-FEE-002` — 稀释感知的区间内份额

历史份额必须使用**历史 active liquidity**；反事实地加入自身流动性 `L` 之后：

```text
share = L / (L_active_historical + L)
```

自身虚拟仓位不存在于历史中，因此**不得**进入历史分母；同时也不得假设加入 `L` 后
其它流动性不变而重复计算两次。

### `M-FEE-003` — 协议费后的净 LP 费用

LP 实收费用必须扣除该 PoolKey 在对应时刻的方向性协议费；总费用与协议费分列，
不得合并成一个不可核对的数字。

### `M-FEE-004` — 单位资金费用与费率密度

按投入资金或按最坏单边库存归一化后的费用收入，用于跨区间和跨池比较。归一化基准
必须随指标一同报告，否则不可比较。

## 4. 价值与库存

### `M-VAL-001` — 计价与合格性

每个价值量必须声明其计价单位与合格状态：`QUALIFIED` 或 `RELATIVE_ONLY`。声明为
`RELATIVE_ONLY` 的结果不得以任何美元符号或 USD 计价字段出现（ADR-014 第 3 条）。

### `M-VAL-002` — 标记价值与可实现价值

`marked_pnl_usdg` 与 `liquidatable_pnl_usdg` 必须分列；后者按当时可执行退出路径、
深度、fee、滑点、税费、hook 和 Gas 估算。缺少合格证据时必须显示 `UNAVAILABLE`，
不得用 spot price 顶替。

### `M-INV-001` — 库存与区间状态

token0 / token1 原始整数数量、`liquidity`、当前 tick、`IN_RANGE` /
`OUT_OF_RANGE` 状态分别记录。区间外不产生费用，库存自然变为单边，且**不得**把
仓位冻结或假设费用继续累积。

### `M-INV-002` — 库存漂移

持有期间两种 token 数量的变化，用于区分"价格变动导致的库存再平衡"与"主动换币"。
两者归因不同，不得合并。

## 5. 基准与归因

### `M-BM-001` — HODL 基准

同期不做任何 LP、保持初始 token 组合的价值路径。

### `M-BM-002` — 理想再平衡基准

在每次价格变动后无成本地重新平衡到目标权重的价值路径。它是 `M-LVR-001` 的参照，
本身不是可实现策略。

### `M-IL-001` — 分歧损失

LP 价值与 HODL 价值之差中由价格路径与区间几何决定的部分。**不得**把分歧损失当作
唯一的机会成本——它不包含 Gas、滑点、税费和再平衡成本。

### `M-LVR-001` — 再平衡损失代理

在本项目的单一场地条件下不存在独立的"真实价格"序列，因此 **V1 只能给出再平衡损失
的代理量**，其参照基准是 `M-BM-002`。报告必须：

- 显式标注为代理；
- 声明所用参照基准和其构造方式；
- 不得声称测量了真实 LVR，也不得跨不同参照基准比较该指标。

### `M-BE-001` — 盈亏平衡波动率

使同一区间、同一窗口内的费用收入等于其再平衡损失代理的已实现波动率水平：

```text
breakeven_vol 满足  fees(range, window) = LVR_proxy(range, window)
```

实现应从回放自身产生的费用序列与再平衡成本序列反解，而不是套用解析近似；近似
公式可以用于交叉检查，但必须同时给出。该指标的量纲是波动率，必须与窗口长度和
年化方式一同报告。

这是本字典中唯一一个直接回答"这个区间现在值不值得做"的标量：当期已实现波动率
低于 `M-BE-001` 时区间 LP 有正的费用边际，高于时费用不足以覆盖库存风险。

## 6. 风险与成本

### `M-RV-001` / `M-RV-002` — 已实现波动率与 EWMA 波动率

按声明窗口计算，必须记录窗口、采样频率和数据来源。窗口不得使用决策时刻之后的数据。

### `M-COST-001` — Gas、滑点与再平衡成本

各项分列并计入总成本；Gas 在总成本中只允许出现一次。Gas 同时以 ETH 数量和其
估值证据记录。

### `M-COST-002` — 换手

单位时间内的 LP 操作量与交易量，作为成本驱动量报告，不单独作为绩效。

### `M-RISK-001` — Episode 回撤与尾部损失

以 episode 为单位报告最大回撤、Expected Shortfall 和最差分位数。回撤基准在
再平衡、重启和资金流之间不得被重置或伪造。

### `M-RISK-002` — 独立 episode 数与不确定性

任何比较必须报告其背后的独立 episode 数量，并在样本允许时给出 bootstrap 区间。
样本不足时输出 `UNCERTAIN`，不得用点估计代替。

## 7. 资金效率与敞口

### `M-CAP-001` — 资金效率

定义为**每单位最坏单边库存资金产生的费用收入**。最坏单边库存指价格到达区间任一端
后该仓位持有的单侧数量。不接受其它定义，也不得把 `liquidityDelta` 直接当作资金。

### `M-SHARE-001` — 区间内流动性份额（时间加权）

区间内自身流动性占 active liquidity 的时间加权比例。这是可测的量；不接受
"active-liquidity utilization" 这类无定义的表述。

### `M-GREEK-001` — 区间内 delta

集中流动性仓位在区间内的即时 delta 等于其库存比例，随价格单调变化；必须与
`IN_RANGE` / `OUT_OF_RANGE` 状态一同报告，因为区间外的 delta 是常数。该指标属于
风险视图，**不得**作为绩效指标使用。

## 8. 禁止用法汇总

- 用费用 APR 单独评价策略表现；
- 用份额分摊估算代替历史费用积分；
- 把自身虚拟流动性计入历史 active liquidity 分母；
- 声称测量了真实 LVR，或跨参照基准比较该代理；
- 在区间不完整时只报年化值；
- 把任一代理量当作真值报告；
- 把 `RELATIVE_ONLY` 结果与 USD 计价结果并列排名；
- 在任何报告中使用未经声明的数据集版本。
