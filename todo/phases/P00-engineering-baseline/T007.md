# T007 — Make the implementation satisfy ADR-006's declared dependency direction

> Phase: `P00`
> Contract status: `OWNER_PLAN_EXTENSION_2026-09-19`

## Dependencies

T006

## Outcome

the three import edges that contradict ADR-006 are repaired instead of excepted: the strategy
package no longer imports the concrete backtest package, the reconstruction modules no longer
import a concrete storage module, and the hook-pack module no longer imports the config layer —
while every behaviour those modules produce today is unchanged and the layer check passes with no
exception entry left for any of the three.

## Deliverables

1. `src/robinhood_lp/strategy/baselines.py` stops importing `robinhood_lp.backtest.engine` and
   `robinhood_lp.backtest.events` (lines 102 and 106 at this task's base commit): the contracts the
   baselines genuinely share with the engine — the decision request, its response, the event type
   and the event-kind and source-priority constants the baselines read — move into a lower
   contracts/domain module that both layers may import, and the engine and the baselines import
   them from there. A genuinely shared type moves to the lower module rather than creating a
   sideways dependency; the rule itself is not relaxed, and the engine's callback contract keeps
   its field names, semantics and units.
2. `src/robinhood_lp/replay/replayer.py` and `src/robinhood_lp/replay/ticks.py` stop importing
   `robinhood_lp.storage.schema` (line 83 and line 87 at this task's base commit): the log-record
   contracts the reconstruction layer consumes are declared by a module that carries no I/O and is
   not a storage or RPC adapter implementation, the reconstruction modules consume records through
   the input they are given rather than by reaching into the storage adapter, and the storage
   adapter still produces the same records for the same raw input.
3. `src/robinhood_lp/qualification/hook_pack.py` stops importing `robinhood_lp.config.models`. The
   module's own docstring is the statement that is made true, not deleted: the module keeps the
   dependency boundary it declares there (the protocol layer, the discovery layer and the
   second-pool resolver surface), and the hook flag-bit constants it needs come from the protocol
   layer, which is where shared immutable protocol values live. One canonical definition of those
   flag bits exists under `src/robinhood_lp/`, and the flag values and the pack's canonical output
   are unchanged.
4. Any module this change adds is classified by the layer map T006 delivers, at a layer that
   already exists in `docs/spec/architecture/ARCHITECTURE.md` §2.1. No new layer, package default
   or per-module override is added in order to make a finding disappear.
5. The three edges are enforced, not only repaired: a committed regression test, parsed from the
   sources with the standard library's `ast` and never imported or executed, fails if a module
   under `src/robinhood_lp/strategy/` imports `robinhood_lp.backtest`, if a module under
   `src/robinhood_lp/replay/` imports `robinhood_lp.storage` or `robinhood_lp.rpc`, or if
   `src/robinhood_lp/qualification/hook_pack.py` imports `robinhood_lp.config`.
6. A file this task may write that cites a moved symbol by its old module — including
   `docs/implement/strategy/AUTHORING_GUIDE.md` and `docs/implement/strategy/example_strategy.py`
   when they exist at this task's base commit — is updated in the same change, so the move leaves
   no stale citation behind it. A citation in `docs/spec/` or in a task contract is reported and
   routed instead of edited.

## Acceptance

every exception entry in the registry T006 delivers (`docs/implement/ci/suppressions.toml`) whose
rule or location covers one of the three sites — the module and the module it imported, or the
source line — is deleted rather than renewed, and the layer check passes with those entries absent;
the entries that record the separate questions the Owner deferred (the packages ADR-006 does not
classify) are left as they are; the three imports above are absent, and the regression of
deliverable 5 fails when one of them is reintroduced, because a check that never fires is
indistinguishable from one that passes; the existing suites for the affected layers
(`tests/test_replay_t040.py`, `tests/test_tick_liquidity_t041.py`, `tests/test_hook_pack_t043.py`,
`tests/test_strategy_t062.py`) pass unchanged, and the recorded outputs of the engine, the replay
and the hook pack are byte-identical before and after, so the change is a move of contracts and not
a change of behaviour; `pytest`, `ruff check`, `ruff format --check` and `mypy src tests` pass.

## Must not

relax the tier order, the layer map, §2.1 or §2.2 to make a violation disappear; renew, extend or
re-scope an exception entry for one of the three sites instead of removing the edge; fix a
different layering question, or touch a package ADR-006 does not classify — the Owner deferred the
layer question for those packages to a separate ADR and T006 keeps them as dated exceptions;
change product behaviour, a public interface's semantics, a numeric result, a reason code or an
error class; delete a module, an import or a §2.2 row to make a rule pass; edit `docs/spec/`, a
task contract, `tools/workflow/`, `.claude/`, `todo/schemas/` or `todo/config.yaml` — a stale
citation this change creates is reported and routed, not patched; add a third-party dependency or
a network read; skip, xfail or otherwise step past a finding; weaken an existing CI job, test or
assertion.
