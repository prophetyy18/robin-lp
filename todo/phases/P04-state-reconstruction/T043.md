# T043 — Build hook semantics evidence packs

> Phase: `P04`
> Contract status: `FROZEN_FROM_BASELINE_6C31778`

> Owner amendment A0002 (2026-09-18): hook evidence covers the pools T038 includes,
> and the case of no hooked pool is recorded as explicit empty-set evidence instead
> of an unverified claim.

## Dependencies

T023, T042

## Evidence scope

Hook packs are produced only for pools whose hooks are nonzero. The pools this task
covers are the pools included in T038's qualified dataset: the re-acquired ZZZ/USDG
reference pool and the Owner-pinned second pool.

If neither included pool has nonzero hooks, this task still produces reviewable
evidence instead of nothing, recorded as its own artifact alongside the per-pool
classification outcomes:

- the per-pool T023 classification outcome for each included pool, carrying the
  observed `hooks` value and the classification reason that produced its level;
- the reason no hook pack exists for that pool;
- an explicit statement that no hook semantics were verified by this task, so the
  empty set is never summarised, reported or accepted as though hook behaviour had
  been checked.

The empty-set path does not relax anything below: a pool whose hooks are nonzero and
that is promoted beyond `ingestion` still needs a complete pack, and a hook-flag
value is never treated as evidence of semantics.

## Outcome

each promoted hooked pool has versioned, reviewable economic semantics.

## Deliverables

hook address/code hash/proxy implementation and upgrade authority,
flags, verified source/ABI, before/after deltas, dynamic-fee behavior, external
state dependencies, replay model, adversarial tests, and invalidation rule.
When no included pool has nonzero hooks, the empty-set evidence defined above is
the deliverable instead.

## Acceptance

fork/golden transactions cover every enabled callback and return-
delta path; model matches observed receipts/state; code/implementation change
invalidates the pack and demotes the pool. If no included pool is hooked, the
recorded per-pool T023 classification outcomes and the stated reason no pack exists
are complete and reproducible, and the result claims no hook verification.

## Must not

promote closed-source/unverified behavior beyond ingestion, equate flags
with semantics, or generalize evidence from one hook deployment to another.
