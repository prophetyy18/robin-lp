# T063 — Add experiment manifests and reports

> Phase: `P06`
> Contract status: `FROZEN_FROM_BASELINE_6C31778`

## Dependencies

T062

## Outcome

every published result is reproducible and auditable.

## Deliverables

manifest with dataset/schema/code/dependency revisions, chain,
PoolKey, interval, strategy parameters, seed, clock/fill/cost/quote assumptions;
in addition to everything above, the dataset version the run consumes and the
reporting numeraire with its valuation qualification (ADR-014); the unit requirement
covers every quantity the manifest records in both lists, not only the two fields added
here — the interval, a block bound, a latency, a cost and a quote assumption included;
decisions, ledger, metrics, and report checksums.

the manifest is per pool: it records exactly one `(chain_id, PoolKey)`, that pool's own
block range and interval, its own decisions, ledger, metrics and report checksums, and
never another pool's. A run covering more than one pool is one run identity over one
dataset version and one reporting numeraire, publishing one manifest per member pool, so
the panel T101 assembles and the pool holdout T064 evaluates are selections over a run's
manifest set rather than fields inside one manifest. Basis: ADR-014's Consequences record
that a run manifest currently holds a single `pool_id` and must be per-pool or widened
before a multi-pool run is claimed, and that partitions and checkpoints are keyed by
`(chain_id, contract_address, pool_id)` per row; per-pool is chosen rather than widened
because the dataset T100 delivers already binds the member pools and each member's
range, so a widened manifest would duplicate that registry.

## Acceptance

one command reruns a saved manifest; total/annualized return, drawdown,
turnover, time in range, fees, IL/LVR proxy, gas/slippage and benchmark excess
reconcile; tampered inputs fail checksum validation; a run whose manifest omits the
dataset version or the reporting numeraire, or whose recorded numeraire disagrees with
the dataset's own qualification record, fails validation instead of publishing; a
multi-pool run publishes one manifest per member pool under one run identity, and a
manifest that carries another pool's data or results fails validation.

## Must not

overwrite a prior run or publish a chart without manifest/coverage; publish a result
without the dataset version and reporting numeraire it depends on, or present a
`RELATIVE_ONLY` run as USD-denominated.
