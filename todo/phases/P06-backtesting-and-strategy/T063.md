# T063 — Add experiment manifests and reports

> Phase: `P06`
> Contract status: `FROZEN_FROM_BASELINE_6C31778`

## Dependencies

T062

## Outcome

every published result is reproducible and auditable.

## Deliverables

manifest with dataset/schema/code/dependency revisions, chain,
PoolKey, interval, strategy parameters, seed, clock/fill/cost/quote assumptions;
in addition to everything above, the dataset version the run consumes and the
reporting numeraire with its valuation qualification (ADR-014), each recorded with its
unit where it is a quantity; decisions, ledger, metrics, and report checksums.

## Acceptance

one command reruns a saved manifest; total/annualized return, drawdown,
turnover, time in range, fees, IL/LVR proxy, gas/slippage and benchmark excess
reconcile; tampered inputs fail checksum validation; a run whose manifest omits the
dataset version or the reporting numeraire, or whose recorded numeraire disagrees with
the dataset's own qualification record, fails validation instead of publishing.

## Must not

overwrite a prior run or publish a chart without manifest/coverage; publish a result
without the dataset version and reporting numeraire it depends on, or present a
`RELATIVE_ONLY` run as USD-denominated.

## References

R17, R19, ADR-014, `docs/spec/research/DATASET_AND_EVALUATION.md`.
