# T069 — Deliver the product-level backtest run entry point

> Phase: `P06`
> Contract status: `OWNER_PLAN_EXTENSION_2026-09-20`

## Dependencies

T041, T053, T061, T063, T068

## Outcome

one product-level entry point turns a registered strategy, its parameters, a data range
and the run assumptions into a reproducible experiment manifest and report, with status,
progress, failure and cancellation observable, and with no Web session required to run it.

## Deliverables

a run request naming the dataset version, the registered strategy identity and its
parameters, the pool and block range, and the seed, fill, cost and quote assumptions the
T063 manifest records; orchestration that joins stored partitions, replay, features, the
engine and the manifest into one run without defining any of them a second time; a run
state surface covering queued, running with progress, failed, cancelled and succeeded,
durable across a process restart and carrying a reason code for every failure and
cancellation; cancellation that stops a run without publishing a partial or
complete-looking result; and a documented command that starts, lists, observes and cancels
a run with no Web process running.

## Acceptance

a run over two heterogeneous pool fixtures produces exactly the manifest and reports the
T063 contract defines (test, golden); re-running the same request reproduces
byte-equivalent canonical artifacts (test); a cancelled run and a failed run publish no
manifest and no report, and a restart while a run is in progress neither duplicates the
run nor loses its state (test); a request naming an unregistered strategy identity, a
missing dataset version, or a range outside the dataset's own coverage fails closed before
any result is written and records its reason (test); every command starts, observes and
cancels a run while no Web process is running (test).

## Must not

mutate stored partitions, approvals, risk configuration or the strategy registry; publish
a result without its manifest and coverage; create a second engine, manifest or feature
implementation beside the ones T061, T063 and T050–T053 own; keep run state only in
memory; write a credential, endpoint alias or key material into the run record; or make a
Web session necessary to start, observe, cancel or reproduce a run.
