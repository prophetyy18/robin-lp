# T013 — Build independent protocol conformance vectors

> Phase: `P01`
> Contract status: `FROZEN_FROM_BASELINE_6C31778`

## Dependencies

T010

## Implementation status

PoolId/Math Foundry generators and JSON vectors exist; acceptance is
open because required checksums/manual-review evidence and a clean reproducible run are not
retained for every edge class.

## Outcome

Python tests do not validate themselves; a Foundry-regeneration drift test byte-compares committed fixtures against a fresh oracle run; every edge class has at least one reviewer whose identity is verifiable by git or GPG, not by agent self-attestation.

## Deliverables

pinned Foundry/TypeScript vector generator; immutable JSON vectors with a per-edge-class `reviews` block in `_meta` (carrying `edge_class`, `vector_names` (list of strings), `reviewer` (string), `reviewed_at` (ISO-8601 UTC), `content_sha256` (hex), `signature_method` (one of `git-author-commit`, `gpg`), and `review_ref` (string)); provenance manifest with repository commits / tool versions / checksums and a Manual-Review subsection that links to `tests/test_oracle_review_provenance.py` and `tools/reviewers/allowed_signers`; a Foundry-regeneration drift test (`tests/test_oracle_drift.py`) that shells out to `forge test --json`, byte-compares against the committed JSON, fails closed on any byte mismatch, and `pytest.skip`s with an actionable message when `forge` is not on PATH.

## Acceptance

a clean generator run reproduces committed vectors **byte-exactly**; intentional source/version drift fails (changing any byte in `tests/fixtures/protocol/{pool_id_vectors.json,math_vectors.json}` causes `tests/test_oracle_drift.py` to fail); every edge class has at least one reviewer entry whose `signature_method` is verifiable by `git log` or `gpg --verify`, the reviewer is not the candidate Developer, and the reviewer's `review_ref` contains trailers matching the JSON record; the `forge`-missing skip path is recorded as `pytest.skip` with the actionable message, never as a passing test.

## Must not

import Python production math into the oracle or fetch mutable `main`
during tests;
treat a `forge`-absent environment as a passing drift test; treat a file-existence check as a substitute for byte-comparison; accept a review entry whose author matches the candidate Developer.
