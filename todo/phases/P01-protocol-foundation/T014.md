`emit log_named_bool("round_up", roundUp);`. The pinned toolchain for the

longer exposes `log_named_bool`; the missing symbol fails `forge build`

appears as `0` / `1` in the test log instead of a textual `false` /
`true`, matching the convention already used for the surrounding `log_named_uint` emissions.
