# T012 — Port V4 tick, price, liquidity, and amount math

> Phase: `P01`
> Contract status: `FROZEN_FROM_BASELINE_6C31778`

## Dependencies

T010

## Implementation status

TickMath, floor amount deltas and liquidity calculations exist;
acceptance is open because protocol math still exposes float conversion, and the required
exact-in/out rounding, decimal classes and complete boundary vectors are not demonstrated.

## Outcome

Python reproduces Solidity bounds and rounding exactly; both `roundUp=true` and `roundUp=false` paths for `getAmount0Delta` and `getAmount1Delta` are exposed in the Python API, each verified against a Foundry-emitted pinned vector, and the caller never adds 1 to a rounded-down result.

## Deliverables

tick/`sqrtPriceX96`, raw amount, display price at a named Decimal boundary, liquidity, bounded position amount, and usable-tick functions with units and rounding documented; `get_amount0_delta` and `get_amount1_delta` accept `round_up: bool` and return the Solidity-correctly-rounded result; the `sqrt_price_x96_to_price` and `price_to_sqrt_price_x96` `float` API is removed from `src/robinhood_lp/protocol/`; a single `Decimal`-typed display helper (for example `to_display_price(sqrt_price_x96: int, decimals0: int, decimals1: int) -> Decimal`) lives at the named display boundary referenced in `docs/spec/architecture/ARCHITECTURE.md` §2.1 and ADR-004 / ADR-009.

## Acceptance

golden/property tests cover MIN/MAX tick, both swap directions,
exact-in/out rounding, 0/6/8/18/24 decimals, overflow/revert domains, monotonicity,
and round trips against a pinned Solidity harness;
**At least one Foundry-emitted vector per rounding direction per function** for `getAmount0Delta` and `getAmount1Delta`: the `amount_deltas` section in `tests/fixtures/protocol/math_vectors.json` contains both `roundUp=false` and `roundUp=true` mirrors for each fixture `(pa, pb, liquidity)` triple. `tools/oracle/src/MathOracle.sol` exposes `amount0Delta(..., roundUp: bool)` and `amount1Delta(..., roundUp: bool)`; `tools/oracle/test/MathOracle.t.sol` emits one vector per direction per function. The display helper uses `Decimal`; the `src/robinhood_lp/protocol/` package has zero `float` symbols in its public API.

## Must not

translate through float, broaden Solidity integer domains, or use a
tolerance where canonical integer equality is possible;
require the caller to add `1` to a rounded-down amount-delta result; re-export a `float`-typed helper from `src/robinhood_lp/protocol/`.
