# T087 — Build the strategy registry and backtest run page

> Phase: `P08`
> Contract status: `OWNER_PLAN_EXTENSION_2026-09-20`

## Dependencies

T068, T069, T084

## Outcome

the owner can see which strategies exist with their parameter schema, version and code
provenance, choose one with its parameters and a range, trigger a run, and watch or cancel
it — in the console, without developer tools.

## Deliverables

the `WEB-PAGE-012` surface inside the authenticated console shell: a strategy list that
shows every registered strategy's identity, parameter schema, version and code provenance
as T068 records them; parameter entry driven by that schema, so a parameter the registered
strategy does not declare cannot be submitted; a range selection that shows the data
coverage behind it rather than a bare date guess, resolving that coverage from the
validated T105 registry-bound manifest of a T069 run and displaying, as recorded, the
dataset version, the member pool and its block range, the covering run identity, and the
registry revision and parameter-schema identity and version the coverage was produced
under; a trigger for the T069 run entry point; and a run list showing each run's status,
progress, failure reason and cancellation result, distinguishing a cancelled or failed run
from a completed one, with every coverage and provenance field it shows resolved through
the validated T105 manifest linked by that T069 run rather than restated from the page.

Explicit empty, partial, conflicting and stale states on every part of the page: no
registered strategy, no dataset covering the chosen range, a run whose state surface is
unavailable, and a registry that has changed under an open form each render the
`WEB-GLOBAL-002` unknown or conflicting state instead of a value.

A legacy pre-registry `T063` manifest is never parsed as current: it is preserved read-only
and byte-identical, appears only as an explicitly labelled historical artifact, and no
coverage interval, registry revision, parameter-schema identity or strategy identity is
ever inferred, substituted or backfilled from it. A failed, cancelled, missing or
revision-mismatched run shows the `WEB-GLOBAL-002` fail-closed evidence state, offers no
selectable coverage and no result, and states its reason rather than a range or a value;
a requested range outside the coverage the current manifest records is refused rather than
silently widened.

## Acceptance

every `WEB-PAGE-012` requirement maps to component and API tests; triggering a run from the
page submits the registered identity, its schema-validated parameters and the selected range
to the T069 entry point and shows the same run identity that entry point reports (test); a
parameter outside the registered schema, an unregistered strategy and a range with no
coverage are refused with the reason shown, not submitted (test); a cancelled or failed run
is never displayed as completed and exposes its reason code (test); a run started from the
page continues and remains observable when the browser session ends, and the page shows the
run's state after the session is re-established (test); a range selection backed by the
validated T105 manifest of a T069 run displays the coverage with the recorded dataset
version, member pool, covering run identity, registry revision and parameter-schema
identity, and repeated renders of the same manifest are identical (test); a legacy
pre-registry `T063` manifest, a manifest that is not the validated current artifact of its
run, an unregistered strategy identity, and a registry, schema or code revision that
disagrees with the recorded revision are each refused as selectable coverage with the reason
shown rather than resolved, substituted or inferred (test, fixture); a failed or cancelled
run offers no selectable coverage and no result (test); a migration fixture keeps every
legacy `T063` manifest and its checksums byte-identical and visibly legacy (fixture); and
an old-path-unreachable assertion proves no current page or API path can consult the
predecessor `T063` hard-coded-identity manifest as a current authority (test); no research
page and no execution approval is reachable from this page (test).

## Must not

mutate stored data, approvals or the registry from the page; invent a strategy identity
outside the registry; hide a failed, cancelled or losing run; present a run's status as a
performance result; expose a generic form that reaches an arbitrary action; treat the
page's availability as the run's availability; parse a legacy pre-registry `T063` manifest
as current input or infer a coverage, registry, schema or identity field it does not record;
or offer selectable coverage from a failed, cancelled, missing or revision-mismatched run.
