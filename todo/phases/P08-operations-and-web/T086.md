# T086 — Validate complete owner journeys and Web security

> Phase: `P08`
> Contract status: `FROZEN_FROM_BASELINE_6C31778`

## Dependencies

T083, T085

## Outcome

a clean owner can perform and explain the supported V1 workflow safely.

## Deliverables

scripted journeys for token input, dossier review, one-pool selection,
strategy comparison, preliminary paper, permissions, incident/takeover and evidence
export; research-surface journeys in which no research page is reachable from, or
confusable with, an execution-shaped control and in which a saved dataset or model
definition cannot be read as, offered as, or promoted to an execution approval (the
four research pages owned by T103 — `WEB-PAGE-008`–`WEB-PAGE-011` — carry their own
journeys in that task and are not re-scripted here); every journey that displays a
result rendering a `RELATIVE_ONLY` dataset visibly distinguishable from a
USD-denominated one, with no USD-denominated field for it; accessibility, viewport and
Web security report with screenshots/results.

## Acceptance

clean-profile runs require no database edits/developer tools; each blocked
or executed decision is explainable; authentication/CSRF/session tests pass; no secret
appears in DOM, network payload, logs, screenshots or exports; no journey reaches a
research page or research definition from an execution-shaped control or presents one
as an execution approval; and every journey that displays a result renders a
`RELATIVE_ONLY` dataset visibly distinguishable from a USD-denominated one and shows
no USD-denominated field for it.

## Must not

mark a journey complete through mocked UI-only state or hide inaccessible
control/evidence paths.

## References

`docs/spec/product/WEB_CONSOLE.md`, ADR-014 (the execution boundary a research
artifact must not cross), T085 (the versioned write path a research definition uses),
T103 (the four research pages that carry their own journeys).
