# T088 — Build the backtest result page

> Phase: `P08`
> Contract status: `OWNER_PLAN_EXTENSION_2026-09-20`

## Dependencies

T069, T084

## Outcome

a completed backtest run can be read on one page as the agreed visualization: price with
the LP tick Range band and every lifecycle event on it, the layering that keeps the
always-on summary honest, and the companion charts that make the result auditable rather
than convincing.

## Deliverables

the `WEB-PAGE-013` surface inside the authenticated console shell. It renders, for one
chosen run and the validated T105 manifest and coverage its T069 run published: a price
series carrying the LP tick Range band and the entry, increase, decrease, collect, rebalance
and exit markers at the blocks they happened; an equity chart with drawdown; a PnL
attribution that splits principal price change, LP fee, Gas, slippage, Hook delta, swap and
rebalance cost, and carries an explicit unexplained residual instead of folding it into
another bucket; an
inventory chart showing `liquidity` and both tokens' raw integer amounts; a tick liquidity
distribution; and a data coverage chart that draws a gap as a gap. Price is never replaced
by the return curve, and `liquidityDelta` is never labelled as a currency amount.

Information access uses the `WEB-GLOBAL-007` layering, so the always-on layer states the
run identity, dataset version, reporting numeraire and the summary figures, the hover layer
adds bounded per-event or per-bucket detail, the pinned drawer holds the detail a reader
fixed deliberately, and the full table exposes every row the page has. Each layer keeps the
page readable without a hover, and each value remains traceable to the manifest, coverage or
decision record it came from.

Every checksum this page reconciles is the one the validated T105 manifest linked by the
chosen T069 run records: the result, coverage and attribution checksums reconcile solely
against that manifest, and a checksum that does not reconcile, a manifest that is not the
validated current artifact of its run, a registry, schema or code revision that disagrees
with the recorded revision, and a run that is failed, cancelled or incomplete each render
the `WEB-GLOBAL-002` fail-closed state with the reason shown instead of a number or a
complete-looking chart. A historical result or manifest is preserved byte-identical and
rendered with an explicit legacy, non-current marker; a legacy pre-registry `T063` manifest
is never reconciled against as current authority, no registry, schema or checksum field is
inferred from it, and it grants this read surface no approval, execution or promotion
authority.

## Acceptance

every `WEB-PAGE-013` requirement maps to component and API tests; a run whose decision
stream contains an entry, an increase, a decrease, a collect, a rebalance and an exit
renders each marker at its recorded block, and a run with no such event renders none
(test, fixture); the PnL attribution's buckets and its unexplained residual reconcile to
the run's own reported total (test); a coverage interval with no data is rendered as an
absence and never as an interpolated or zero-filled series, and a coverage interval that is
missing, not yet ingested and failed are distinguishable (test); a hover layer shows no more
than the bounded number of rows the layering rule allows and the full table shows every row
(test); a dataset whose qualification is `RELATIVE_ONLY` renders relative results with no
USD-denominated field (test); and a run whose manifest or coverage is absent renders the
`WEB-GLOBAL-002` unknown state rather than a chart (test); the result, coverage and
attribution checksums displayed for a completed run are the ones its validated T105
manifest records, and a checksum trace reconciles each of them to that manifest (test); a
tampered, mismatched or wrong-revision checksum, and a manifest that is not the validated
current artifact of its T069 run, block the display with the reason shown rather than
rendering a reconciled figure (test); a migration fixture keeps the historical results and
their `T063` manifests byte-identical and visibly legacy while a compatibility fixture
renders them as explicitly non-current and never reconciled against as current authority
(fixture, test); a failed, cancelled or incomplete run renders no complete-looking result
(test); and an old-path-unreachable assertion proves no current display path reconciles
against the predecessor `T063` hard-coded-identity manifest (test).

## Must not

interpolate, zero-fill or connect a gap; present a simulated fill, a fee estimate or a
residual as a measured value; hide a losing or failed run; render a number whose source
cannot be reached from the page; label `liquidityDelta` or a raw integer amount as a
currency amount; mutate domain state from this read surface; reconcile a current result
against a legacy pre-registry `T063` manifest or treat one as current authority; infer a
registry, schema, checksum or coverage field a manifest does not record; or render a
complete-looking result for a failed, cancelled or incomplete run.
