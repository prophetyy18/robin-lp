# T088 — Build the backtest result page

> Phase: `P08`
> Contract status: `OWNER_PLAN_EXTENSION_2026-09-20`

## Dependencies

T084, T109

## Outcome

a completed backtest run can be read on one page as the agreed visualization: price with
the LP tick Range band and every lifecycle event on it, the layering that keeps the
always-on summary honest, and the companion charts that make the result auditable rather
than convincing.

## Deliverables

the `WEB-PAGE-013` surface inside the authenticated console shell. For one chosen successful
T109 run it consumes the validated `ReplayFrame(run_id, cursor)` contract and provides a
`MarketCursor` scrubber. Each frame renders the post-event `MarketState` and the exact saved
post-transition `RunState` at the same cursor: a price series carrying the LP tick Range band
and the entry, increase, decrease, collect, rebalance and exit markers at their recorded
cursors; an equity chart with drawdown; a PnL attribution that splits principal price change,
LP fee, Gas, slippage, Hook delta, swap and rebalance cost, and carries an explicit unexplained
residual instead of folding it into another bucket; an inventory chart showing `liquidity` and
both tokens' raw integer amounts; a tick liquidity distribution; and a data coverage chart that
draws a gap as a gap. Price is never replaced by the return curve, and `liquidityDelta` is never
labelled as a currency amount.

The scrubber preserves T109 cursor semantics: a block-only choice means end-of-block, a
pre-first-event choice returns recorded initial state, and an exact cursor shows the market
after its event and the run after all same-cursor transitions in original
`run_transition_ordinal` order. The page consumes that order as recorded and never sorts,
backfills or replays strategy callbacks. A delayed fill is absent at its trigger cursor and every
intervening cursor and appears only at the later cursor whose market event supplied its fill
data. T104 remains the sole source of historical fee-growth and exact range-fee values; every
such displayed value carries T104's matching dataset/window/reconstruction provenance beside it.
This task contains no second fee, replay, backtest or accounting projection.

Information access uses the `WEB-GLOBAL-007` layering, so the always-on layer states the run
identity, dataset version, reporting numeraire and summary figures, the hover layer adds bounded
per-event or per-bucket detail, the pinned drawer holds detail a reader fixed deliberately, and
the full table exposes every row the page has. Each layer keeps the page readable without a
hover, and each value remains traceable to the T109 manifest, coverage, simulation evidence,
T104 projection or recorded transition it came from.

Every checksum this page reconciles is the one the validated T109 artifacts linked by the chosen
run record: result, coverage, attribution, canonical dataset and simulation-evidence checksums
reconcile solely against those artifacts. A checksum or dataset/pool/range/cursor/revision/T104
provenance mismatch, a manifest or evidence artifact that is not the validated current artifact
of its run, or a failed, cancelled or incomplete run renders the `WEB-GLOBAL-002` fail-closed
state with the reason shown instead of a number or complete-looking chart. Pre-T109 T105/T063
results and manifests remain byte-identical and may retain an explicitly legacy terminal report,
but exact historical replay is explicitly unavailable: no `RunState` or `ReplayFrame` is inferred
from summaries, hashes or current strategy code. This read surface grants no approval, execution
or promotion authority.

## Acceptance

every `WEB-PAGE-013` requirement maps to component and API tests; a run whose saved evidence
contains an entry, increase, decrease, collect, rebalance and exit renders each marker at its
recorded cursor, and a run with no such transition renders none (test, fixture); the PnL
attribution buckets and unexplained residual reconcile to the run's reported total (test); a
coverage interval with no data is rendered as an absence and never as an interpolated or
zero-filled series, and missing, not-yet-ingested and failed coverage are distinguishable
(test); a hover layer shows no more than the bounded number of rows the layering rule allows and
the full table shows every row (test); a `RELATIVE_ONLY` dataset renders relative results with
no USD-denominated field (test); and an absent manifest, coverage or evidence artifact renders
the `WEB-GLOBAL-002` unknown state rather than a chart (test).

The result, coverage, attribution, dataset and evidence checksums displayed for a completed run
are those its validated T109 artifacts record, and a checksum trace reconciles each one (test).
At pre-first-event, exact intra-block and end-of-block cursors, displayed market/run state follows
T109's post-event/post-transition semantics (test). An A/B/C delayed-execution fixture renders
the decision at trigger A, the reactive intervening cursor B entirely pre-fill, and fill cursor C
post-fill; scrubbing never exposes the fill before C, invokes no strategy callback and performs no
post-sort (test, golden). Historical fees and range-fee values are exactly equivalent to direct
T104 queries with the same dataset/window/reconstruction provenance, and inspection proves no Web
fee implementation exists (test).

A tampered, mismatched or wrong-revision checksum, a dataset/pool/range/cursor or T104-provenance
mismatch, and a manifest/evidence artifact that is not the validated current artifact block the
display with a named reason (test). A migration fixture keeps historical results and predecessor
manifests byte-identical and visibly legacy; their terminal report remains readable but replay is
explicitly unavailable and no current strategy callback, inferred transition or reordered audit
history can make it available (fixture, test). A failed, cancelled or incomplete run renders no
complete-looking result, and an old-path-unreachable assertion proves no current display path
reconciles against a T069/T105/T063 predecessor publisher or constructs a second projection
(test).

## Must not

interpolate, zero-fill or connect a gap; present a simulated fill, fee estimate or residual as a
measured value; hide a losing or failed run; render a number whose source cannot be reached from
the page; label `liquidityDelta` or a raw integer amount as a currency amount; mutate domain state
from this read surface; rerun a strategy callback; sort or reinterpret recorded transitions;
expose a delayed fill before its fill cursor; replace or duplicate T104; reconcile a current result
against a pre-T109 T105/T063 artifact or infer a registry, schema, checksum, cursor, transition or
coverage field it does not record; present legacy evidence as exact replay; grant approval,
execution or promotion authority; or render a complete-looking result for a failed, cancelled or
incomplete run.
